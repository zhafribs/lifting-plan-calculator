# Lifting Plan Calculator 2.5.3

**Released 14 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

The printed plan is rebuilt around cards: Plan details and the lift inputs read
at a glance, every following section shares the same card, and the report can be
written straight to a 1-inch-margin PDF from Summary. The working-range diagram
can be attached to the plan and refreshes with the crane and jib configuration.

## Highlights

- **A PDF export that does not use the print dialog.** *Save as PDF* writes A4
  with one-inch margins on every side, using a headless Chromium build — Edge on
  Windows, Chromium on Linux. It asks only where to save the file and reports the
  saved path; if no renderer is installed it says so instead of writing a bad
  file.

- **A footer on every page.** The plan reference sits on the left, the credit
  line in the centre, and `n / total` on the right. The centre text is editable
  in Summary, between Plan details and Export. The old single footer at the end
  of the report is gone.

- **The plan reads as cards.** Plan details is section 1 and the lift inputs are
  section 2; the inputs are figure cards like the load figures. Geometry,
  rigging, final capacity, note, nonuniform load and tandem lift all use the
  same card, so the printed sheet has one rhythm instead of a mix of forms and
  loose headings.

- **The working-range diagram is part of the plan.** Tick *Working range
  diagram* in Summary, between Crane and Uniform Load, and the current diagram
  appears at the bottom of Plan details. It re-renders from the crane and jib
  configuration on every build and is inverted to a light background for
  printing.

- **A quieter head.** The title reads `Lifting Plan - <crane name>` on one line;
  the six deciding figures are cards; the two workings sit side by side under
  centred labels. The repeated configuration line, capacity pill, chart-source
  line and booked-rating note are gone.

## Changed

- The issued date is printed as `DD-MM-YYYY`.
- The crane's plate capacity is labelled **Crane rating**; a passing booked check
  says `checked against 75%`, and a failure names both the rating and the
  requirement.
- The lift inputs no longer repeat the load weight; the gross load is in the
  plan head.
- The printed plan's foot carries the footer rather than the scope sentence; the
  scope statement remains in the readme.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- No plan is stored between launches, so there is nothing to migrate. On Linux,
  *Save as PDF* needs Chromium; Windows uses the Edge that ships with the system.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
