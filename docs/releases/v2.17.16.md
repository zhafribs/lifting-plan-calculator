# Lifting Plan Calculator 2.17.16

**Released 26 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Tabs load when first opened, and report previews reuse their diagram instead of
rebuilding it on every edit. Two lockfile advisories are closed. No calculation,
report content or PDF layout changed.

## Changed

- **Tabs are built on first visit.** Startup constructs only the landing screen;
  the other tabs are created when opened and reused afterwards. Summary still
  builds the hidden Graph renderer when it needs the working-range diagram, so
  opening Summary first keeps the diagram.
- **Report previews reuse the working-range diagram.** The capture is cached by
  crane state and quality, an edit made during a build wins, and unchanged
  inputs skip the report build. The live preview captures at 2×; Page view, Save
  as PDF/HTML and Print keep the 3× print image.
- **Timing is visible in `ui.log`** as `screen …`, `report diagram`, `report
  build` and `report preview`, so the next performance question can be measured
  rather than guessed.

## Security

- **`cookie` 0.18.3 closes RUSTSEC-2026-0594.** A transitive Tauri/wry
  dependency moved from 0.18.2 for the private-nonce fork advisory. No code
  changed.
- **`url` 2.5.9 closes RUSTSEC-2026-0592.** A transitive dependency moved from
  2.5.8 for the stack-overflow advisory. No code changed.

## Notes

- No arithmetic, verdict, limit or report content changed.
- The live preview's diagram is captured at 2×; the printed page keeps the 3×
  image, so the PDF is unchanged in quality.
- The first visit to Summary builds the Graph renderer on that click; later
  visits reuse it.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
