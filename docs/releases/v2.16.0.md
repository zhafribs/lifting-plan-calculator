# Lifting Plan Calculator 2.16.0

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The app now has a shell of its own on Linux — light or dark, following the
desktop, with the desktop's accent colour — instead of one fixed dark skin.

## Added

- **A neutral light and dark palette.** Both are built from the same tokens, so
  every screen, dialog and status band has a counterpart in each. The app reads
  the desktop's light/dark preference (GNOME, KDE, and any desktop that sets the
  GTK colour scheme, Hyprland included) and follows it.

- **The desktop's accent.** Where the desktop publishes one — GNOME's accent
  setting and KDE's selection colour today — the focus rings, links, selected
  tab and primary buttons use it. Where it does not, the app falls back to its
  own blue, one per palette.

- **Match the desktop, Light or Dark, in About.** The default follows the
  desktop; the other two override it. The choice is remembered in
  `~/.config/lifting-plan-calculator/appearance.json` and is the only thing the
  app stores between launches.

## Changed

- Filled buttons (primary, add, danger) now carry their own text colour. Before,
  they inherited the surface text colour, which was unreadable on a light
  palette.
- Windows keeps its Fluent layer; the accent for it comes through the same path
  as Linux's, so the two platforms no longer have separate accent code.

## Notes

- Nothing changed in the calculation engine, the load chart reader, the report
  or the printed diagram.
- The report is printed on white paper and is unaffected by either palette.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- No plan is stored between launches; the appearance file is the only setting,
  and a missing or unreadable one simply means "Match the desktop".

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
