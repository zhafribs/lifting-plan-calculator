# Lifting Plan Calculator 2.7.0

**Released 14 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

Summary now shows the report as the **pages that will print**. The preview opens
on the real A4 PDF, with zoom and a page counter, so you can check where a page
breaks and read a figure at 200% before you save or sign it.

## Highlights

- **Pages, not an approximation.** The report preview opens on **Pages**: every
  page is drawn exactly as *Save as PDF* writes it, footer included, on a grey
  backdrop. Zoom out to see the shape of the plan, or zoom in to read a capacity
  figure, with fit-to-width and a `Page N of M` counter.

- **What you see is what is saved.** *Save as PDF* writes the very bytes the page
  view is showing. If the plan has not changed since you looked at it, it is not
  printed a second time — the file is the document on screen.

- **The fast view is still there.** **Live** keeps the HTML preview that follows
  every keystroke. The page view redraws when it opens, when a section is
  toggled, or when you leave a field — never while you are typing.

## Notes

- **The page view needs the print path.** It renders with the same engine as the
  export: WebKitGTK on Linux, Edge on Windows. If that is unavailable, the
  preview says why and returns to **Live** rather than showing a blank page.
- **Zoom redraws, it does not stretch.** Each page is re-rendered at the new
  scale, so 200% stays sharp instead of turning into pixels.
- **The viewer is bundled, not fetched.** A PDF viewer (pdf.js, Apache-2.0) ships
  inside the app, pinned by checksum, so the page view works offline and on an
  air-gapped machine.
- The viewer is about 1.5 MB of source, which compresses to roughly half a
  megabyte in the AppImage: the Linux file is 79.5 MB.
- No calculation, chart or report layout changed in this release. On Linux the
  PDF is still produced by WebKitGTK and on Windows by Edge, so page breaks can
  differ between the two platforms.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- No plan is stored between launches, so there is nothing to migrate.
- The export needs no browser on Linux; Windows uses the Edge that ships with
  the system.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
