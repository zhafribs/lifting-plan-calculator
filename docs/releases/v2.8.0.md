# Lifting Plan Calculator 2.8.0

**Released 14 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

*Save as PDF* now works on Windows even if Microsoft Edge has been removed or
disabled, and the Summary page view keeps up with you while you type.

## Highlights

- **Windows printing no longer depends on Edge.** The app prints with the
  WebView2 runtime it already needs in order to start at all, so uninstalling
  the browser does not take the PDF export with it. If that runtime is too old
  to print, or the print fails, Edge is still tried before the app reports a
  failure.

- **The page view follows your typing.** Instead of waiting for you to leave a
  field, the **Pages** view redraws about a second after you stop typing. The
  **Live** view stays instant, and the saved PDF is still the document you were
  looking at.

## Notes

- **What "inside the app" means on Windows.** The WebView2 runtime is part of
  the app's own footprint — the installer already ships its bootstrapper, and
  the app cannot run without it. This change stops the export from needing the
  separate Edge *browser*.
- **The footer on Windows** is still drawn by the page's own `@page` rules,
  which the Chromium engine in WebView2 renders. On a WebView2 runtime older
  than Chromium 131 those rules are ignored and the footer would be missing;
  the app cannot detect that before printing, so keep the runtime updated.
- **Linux is unchanged**: WebKitGTK prints, and the footer is written onto the
  pages by the app.
- No calculation, chart or report layout changed in this release.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- No plan is stored between launches, so there is nothing to migrate.
- Windows needs the WebView2 runtime, as it did before; the installer ships the
  bootstrapper.
