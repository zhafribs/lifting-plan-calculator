# Lifting Plan Calculator 2.12.1

**Released 17 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

A Windows fix: the Summary page view no longer flashes a white print window
over the app when it refreshes.

## Fixed

- **The print window is gone.** Every refresh of the page view printed the plan
  through a WebView2 window created off-screen; Windows could still present it,
  so a white window holding the report flashed for a second and vanished.
  Windows now prints with **headless Edge**, which opens no window at all. The
  app's own WebView2 printer remains as the fallback for a machine without Edge,
  and that path now creates its window hidden and shows it only after the
  report has loaded, off-screen.

## Notes

- Nothing changed on Linux or in the report itself: the same pages, margins and
  footer, printed by an engine that never touches the desktop.
- The dependency audit, the signed checksum manifest and the page-margin control
  are unchanged from 2.12.0.
