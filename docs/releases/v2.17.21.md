# Lifting Plan Calculator 2.17.21

**Released 26 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The Pages view shows the report while it prints, the printed diagram's grid is
clean, and a zoomed page can be panned to its left edge. No arithmetic or report
content changed.

## Added

- **The report's first page appears while the PDF prints.** The Pages view shows
  the report at the printed page's size straight away, then replaces it with the
  PDF when the print returns. On a long plan that turns the placeholder into
  the plan itself.

## Fixed

- **Stray diagonal lines across the working-range diagram.** Each grid line now
  starts its own path instead of continuing the previous one, so the printed
  chart has its proper horizontal and vertical grid.
- **The left edge of a zoomed page was unreachable.** Above fit width the page
  centred itself out of reach of the scrollbar; it now stays scrollable on both
  sides.

## Notes

- No arithmetic, verdict, limit, report content, footer or page margin changed.
- The first-page preview is the report, not the PDF: it has no stamped footer
  until the printed page replaces it, and the printed page is the one that
  counts.
- A block that the print pushes whole onto page 2 can appear at the bottom of
  page 1 in the brief preview.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
