# Lifting Plan Calculator 2.17.19

**Released 26 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The printed working-range diagram is now vector, and the Pages view is honest
while the PDF prints. No arithmetic or report content changed.

## Changed

- **The working-range diagram prints as SVG.** The report carries vectors
  instead of a 2700×2100 PNG, so the lines and labels stay sharp at any zoom.
  High-alpha accents are flattened over the diagram background to keep their old
  printed hue; low-alpha fills stay translucent so the grid remains visible.
  Diagram labels use the system sans inside the standalone SVG.
- **The Pages view shows a page-shaped placeholder.** While the PDF prints it
  says "Preparing page 1…" instead of leaving the pane blank behind the
  Rendering status; page 1 appears as soon as the print returns.
- **The PNG path remains the fallback.** If the SVG surface or its measure
  context fails, the report still gets the existing raster diagram.

## Notes

- No arithmetic, verdict, limit, report content, footer or page margin changed.
- The vector diagram's label face can differ from the app's screen face; the
  standalone SVG cannot use the bundled Inter webfont.
- Semi-transparent shapes that overlap one another are an approximation against
  the old flattened pixel; opaque and high-alpha colours match.
- PDF size was not measured against 2.17.18, so this release makes no size
  claim.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.
