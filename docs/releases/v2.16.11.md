# Lifting Plan Calculator 2.16.11

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The sling input section now names its arrangement, and all three arrangements
read as the same kind of card.

## Changed

- **`3. LIFT INPUT PARAMETERS - <arrangement>`.** The first section of a sling
  arrangement is titled with the arrangement that follows:
  `- UNIFORM LOAD`, `- NONUNIFORM LOAD`, `- TANDEM`. The uniform case already had
  it; the other two now match, and the number still follows the cards actually
  printed.

- **Nonuniform and tandem inputs use figure cards.** The same three-column cards
  the uniform inputs use replace the long key/value table, so a reader scans the
  same shape whichever arrangement the plan uses.

## Notes

- Nothing changed in the arithmetic, the load chart reader or the printed
  diagram.
