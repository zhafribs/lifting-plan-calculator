# Lifting Plan Calculator 2.3.0

**Released 11 October 2026** · Linux (AppImage) · Windows 10/11 (x64)

The newer manufacturer workbook format is now wired into the Crane and Graph
tabs: the crane's position on the axis, the longest main boom, and the jib
sheets are read and checked rather than typed around.

## Highlights

- **The new workbook format, wired into the Crane and Graph tabs.** Importing a
  load chart with the `Crane location on axis (X, Y)` cell and the jib sheet
  now:
  - reads the crane's position and keeps the **longest main boom**;
  - offers a **Jib configuration** card — Boom length / + jib / + extended jib
    — where the configuration picks its jib (7.2 m or 12.8 m) and the operator
    chooses one of the offset angles that jib allows, plus the boom angle to
    read the chart at;
  - **auto-chooses the boom angle that passes the 75% rule** at the farthest
    reach, exactly as the working radius is suggested for the main boom;
  - checks the jib table at that angle, with the working radius derived from the
    assembly geometry (measured from the X axis);
  - mirrors the check into the manual entry: derived radius, jib capacity at
    the angle, and the boom written as `34+7.2` / `34+12.8`.

- **The Graph tab follows the workbook.** The crane position comes from the
  workbook, and after manual edits a **Reset to Crane Tab** button restores it.

## Fixed

- Jib offset angles rotate clockwise (below the boom axis).
- Working radii are measured from the x = 0 axis, not from the crane.
- Choosing a dropdown no longer scrolls the page back to its top.
- The workbook table folds behind a toggle.

## Compatibility and upgrade notes

- Older workbooks without a crane-position cell keep working: the import falls
  back to the main-boom matrix on its own.
- **Linux.** glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- **Windows.** Windows 10/11 x64 with WebView2.
