# Lifting Plan Calculator 2.16.3

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

On a wallpaper-themed desktop — the usual Hyprland setup — the app now follows
the wallpaper with the rest of the desktop.

## Added

- **The wallpaper palette drives the shell.** When pywal or wallust has written
  its palette (`~/.cache/wal/colors.json`, `~/.cache/wallust/colors.json`, or the
  plain `~/.cache/wal/colors`), the app takes the most usable colour of that
  palette as its accent and tints its surfaces with the same hue. The lightness
  ladder stays ours, so text contrast does not depend on how bright the wallpaper
  is.

- **It updates without a restart.** The palette is re-read when the window is
  focused, so the next wallpaper change shows up the next time you come back to
  the app.

- **About says where the accent came from** — the wallpaper palette, the
  desktop's accent setting (GNOME and KDE), or the app's own blue.

## Changed

- Nothing in the calculation, the load chart reader, the report or the printed
  diagram. The report is still printed on white, whatever the shell looks like.

## Notes

- The palette is read from the standard cache paths. A generator that writes
  somewhere else (matugen templates, for example) is not discovered; the desktop
  accent or our blue is used instead until such a path is added.
- Only the shell is themed. The plan still prints black on white.
