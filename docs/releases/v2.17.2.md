# Lifting Plan Calculator 2.17.2

**Released 20 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The margins field, the rail tooltips and the Windows install. No figure, limit
or verdict changed, and the report prints as it did in 2.17.1.

## Fixed

- **The page-margin unit sits beside the number, not on the spinner.** On Linux
  the native up/down arrows were drawn under the "mm" suffix in the Summary
  tab's margins panel. The spinner is hidden on both platforms now, and the
  field reserves the unit's space the way every other figure field does.
- **Tooltips are small and drawn by the app.** Hovering a rail tab used to open
  a large black window with the label against one edge. The app draws its own
  bubble, on hover and on keyboard focus; the report preview keeps its
  accessible name without a hover hint.
- **The rail footer fits a small window.** Below 1100px the contact line broke
  the email mid-word, and at the 720×540 minimum the last line ran past the
  window. The contact stays on the About screen, which prints it in full.

## Changed

- **The Windows install looks and behaves like a per-machine app.** The
  publisher is registered in Add/Remove Programs, and the licence, the
  copyright line and the third-party notices are installed beside the
  executable. The installer also carries the WebView2 bootstrapper, so a
  machine that does not have the runtime can still install.
- The install folder is small by design: the frontend, KaTeX and the PDF viewer
  are compiled into the executable, and the C runtime is linked statically.
  There is no runtime folder to break, and no DLL that has to match.

## Notes

- No calculation, report content or PDF layout changed. Page margins still
  default to 25.4 mm.
- Windows installers remain unsigned, so SmartScreen shows "Unknown publisher"
  until a signing certificate is added.
- The Windows build needs Windows 10 (1803 or later) or Windows 11, x64. It runs
  without a discrete GPU; WebView2 falls back to software rendering.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime; the installer
  carries its bootstrapper. The installers are per-machine and replace an
  existing per-user install.
- Updating from 2.17.1 keeps every setting; only the install folder gains the
  licence and notice files.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
