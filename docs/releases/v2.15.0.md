# Lifting Plan Calculator 2.15.0

**Released 18 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The Windows build now wears the Windows 11 Fluent shell, while the lift maths and
the printed report stay exactly as they were.

## Added

- **A Fluent NavigationView rail on Windows.** The rail starts at 240 px with the
  groups and labels, and folds to a 56 px icon strip from the hamburger in its
  header. The compact icons keep their tooltips and the `Ctrl+1`…`Ctrl+8`
  shortcuts. The active tab carries `aria-current="page"`, and the toggle reports
  `aria-expanded`.
- **Windows 11 Mica behind a native title bar.** The Windows build keeps the
  system title bar and asks DWM for Mica, so the window material follows the
  desktop. Windows 10 gets the same Fluent layout on solid surfaces, because
  Mica is not available there.
- **The Windows light/dark setting and accent colour.** The shell switches with
  the system theme while it runs, and the system accent is read through
  `DwmGetColorizationColor`. If that read fails, the Windows 11 accent is used:
  `#0067c0` in light and `#60cdff` in dark.
- **Fluent surfaces and controls.** Segoe UI Variable, Fluent cards, 32 px
  buttons and fields, accent focus rings, Fluent status badges and 40 px list
  rows, with `forced-colors` and reduced-motion coverage.

## Changed

- The Windows styling lives in `ui/css/windows.css`, loaded after the unchanged
  base stylesheet and scoped to the Windows platform marker. Linux and macOS
  keep their existing appearance.
- The README and tutorial describe the Windows 11 shell and the Windows 10
  fallback, with light, dark and compact screenshots.

## Fixed

- Unit suffixes no longer overlap a right-aligned number in a field, so `0 ton`
  and `0 deg` read as one value.
- An expanded Windows rail keeps its labels below 1100 px; the base stylesheet's
  narrow-window collapse no longer overrides the explicit rail state.

## Not changed

- The calculation engine, the load-chart reader, the working-range diagram, the
  printable report and the PDF output.
- The report keeps its own typesetting and colours; only the shell around it
  follows Fluent.

## Notes

- `cargo run -- --platform-preview=windows` previews the Windows layout on Linux
  for design QA. It swaps the tokens only; Mica needs a Windows 11 build.
- A Windows 10 machine shows the solid Fluent fallback, not Mica.
- No plan is stored between launches, so there is nothing to migrate.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.
