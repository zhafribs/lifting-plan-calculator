# Lifting Plan Calculator 2.17.3

**Released 20 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The rail now collapses on Linux, and a per-metre or per-volume load line reads
its two boxes without squeezing the units. No figure or calculation changed.

## Added

- **The navigation collapses on Linux.** The header button that Windows already
  had is on every platform: it folds the rail to a 64px icon strip and back,
  keeps the product name and version in the footer, and leaves the choice alone
  when the window is resized. Until it is clicked, the rail still follows the
  1100px breakpoint.

## Fixed

- **A per-metre or per-volume load line has room for both of its boxes.** "kg/m"
  and its number used to share one 122px cell, so the unit took the width the
  figure needed. The two boxes stack at every window size. Below a 620px card
  the "Measured by" dropdown takes a full-width line and the quantity moves
  beneath it, so "Weight by Volume" is never clipped.
- A fixed-weight line keeps its one-line layout; the change only affects the
  measured-by types that read two values.

## Notes

- No calculation, report content or PDF layout changed.
- The load-line layout applies to both platforms; the rail toggle is new on
  Linux and unchanged on Windows.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime; the installer
  carries its bootstrapper.
- Updating keeps every setting; the rail starts in the same state as the window
  width implies, as before.
