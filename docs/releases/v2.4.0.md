# Lifting Plan Calculator 2.4.0

**Released 11 October 2026** · Linux (AppImage) · Windows 10/11 (x64)

The app now tells you when a newer version exists, and on Windows it can
install it for you.

## Highlights

- **Update reminders.** The app asks GitHub for the newest release at launch,
  and on demand from the About tab. When one exists, a reminder strip appears
  under the topbar: the version you have, the version available, a **Release
  notes** button that opens the release page in the desktop's browser, the
  repository, and a dismiss button.

- **Windows updates from this repository.** On Windows the reminder and the
  About card also offer **Download & install**: the release's installer is
  fetched from the GitHub release, started, and the app closes so the installer
  can replace the running files. The AppImage is only reminded — its release
  page carries the new file, and `appimageupdatetool` still delta-updates it.

## Fixed

- The reminder strip folds without moving the page: the screen keeps the
  flexible grid row, so every tab's layout is untouched whether the strip is
  showing or not.

## Compatibility and upgrade notes

- The only network call is the one the update check makes; nothing about you or
  your plan is sent, and no plan is stored between launches.
- **Linux.** glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- **Windows.** Windows 10/11 x64 with WebView2.
