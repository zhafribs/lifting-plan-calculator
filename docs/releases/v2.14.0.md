# Lifting Plan Calculator 2.14.0

**Released 18 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Every common Linux packaging format now ships from the same release, and the
Windows installers put the app where Windows expects it.

## Added

- **Four new Linux packages.** Each is built from the same release binary and
  uses the distribution's own GTK 3 and WebKitGTK 4.1, so a package update
  updates the libraries with the system instead of carrying a second copy:
  - `.deb` for Debian and Ubuntu — `sudo apt install ./<file>.deb`
  - `.rpm` for Fedora and RHEL — `sudo dnf install ./<file>.rpm`
  - `x86_64.pkg.tar.zst` for Arch — `sudo pacman -U ./<file>`
  - `.flatpak`, one file, on the GNOME 48 runtime — `flatpak install ./<file>`

  The AppImage remains the no-install option, with its delta-update `.zsync`.

## Fixed

- **Windows installs for all users.** The NSIS setup installed per-user, which
  put the app under one profile rather than `C:\Program Files`. Both the MSI
  and the setup are now per-machine, and both show the administrator prompt that
  implies. An existing per-user install is replaced by the per-machine one.

- **No warning from the Windows build.** The AppImage update helper is compiled
  only on Linux, where it is used.

## Notes

- Nothing changed in the calculation engine, the load chart reader, the report
  or the page-margin control.
- The Flatpak needs its runtime once: `flatpak install` fetches
  `org.gnome.Platform//48` if it is not already on the machine.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- No plan is stored between launches, so there is nothing to migrate.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
