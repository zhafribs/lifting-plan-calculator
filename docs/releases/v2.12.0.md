# Lifting Plan Calculator 2.12.0

**Released 17 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

The window now runs under a content policy, and the crane tab's jib rules use the
chart's own basis.

## Security

- **The window runs under a Content-Security-Policy.** Scripts load only from the
  app's own origin, so an inline script or an inline event handler no longer
  runs. Nothing may be fetched from another origin; the IPC endpoints are the only
  connection target; plugins and forms are off.

- **The report's typesetting is a file, not an inline pass.** KaTeX is started by
  `vendor/katex/lpc-autorender.js` instead of an inline `<script>`, and the
  preview learns whether the equations typeset from a message rather than by
  reading the frame's document. A sandboxed preview frame was tried and rejected:
  an opaque origin makes `script-src 'self'` match nothing, so the equations
  would not typeset.

## Fixed

- **Returning to "Boom length" restores the main boom.** Clicking back from a jib
  configuration now returns to the import's own basis — the farthest charted
  radius within the 75% rule, its row mirrored, the jib's table and angle cleared
  — instead of keeping the jib's reach and a zeroed boom angle.

- **A crane with no extended jib no longer offers one.** When the workbook
  carries a single jib length, "Boom length + extended jib" is disabled and
  greyed on the Crane and Graph tabs, and the selection is refused before it
  reaches the engine.

- **The Graph tab's boom angle drives the Crane tab.** It no longer requires a
  workbook or a live working radius. With a workbook, an angle edit also
  publishes the reach it produces, so the chart check and the printed diagram
  agree with the printed angle; dragging the crane itself leaves the radius
  alone.

- **A jib boom angle between chart rows uses the lower row.** Capacity rises with
  the boom angle, so a value between two charted angles must never borrow the
  higher row. With rows at 60° and 65°, a boom at 64° is checked at 60°: the
  Crane tab's angle select shows 60°, and the capacity is the 60° row's. Below
  the first row there is no conservative row, and the angle is refused as outside
  the chart.

## Notes

- No other calculation changed. The working radius and the diagram are still
  drawn at the boom's real angle; only the jib chart lookup uses the lower row.
- The report, the PDF export and the updater are unchanged. The 2.10.0 signing
  key and `SHA256SUMS.txt.sig` are unchanged; this release is signed with the
  same key.
- Windows installers still carry no Authenticode certificate. The free
  open-source application has been submitted; until it is accepted, a manual
  download still shows "Unknown publisher", and the in-app update path does not
  depend on that warning.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- No plan is stored between launches, so there is nothing to migrate.
- Windows needs the WebView2 runtime, as before.
- The content policy applies to the app's own window: the report preview still
  renders its equations, the PDF export is unchanged, and no network access was
  ever required.
