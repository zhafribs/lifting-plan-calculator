# Lifting Plan Calculator 2.13.5

**Released 18 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

The working-range diagram on the plan is now large enough to read and sharp
enough to print.

## Fixed

- **The diagram fills the page.** It was capped at 78 mm of height, about a
  third of the sheet, which made every dimension label tiny. It now spans the
  report's full text width — roughly 159 mm with one-inch margins — so the
  radius, height, angle and tip figures read at the report's own label size.

- **It is captured at print resolution.** The snapshot is drawn at three times
  the screen size instead of two, which is about 2700 px across: more than the
  1878 px a 300 dpi print needs, so the lines and numbers stay sharp on paper.

- **Its labels are 25 % larger on the page.** The screen sizes are tuned for the
  diagram's on-screen canvas; the capture enlarges them for print without
  changing how the Graph tab looks.

## Notes

- Nothing else changed: the same crane, jib and angle produce the same diagram,
  and the page view, the saved PDF and the printed plan all show the larger one.
- The diagram is still inverted to a light background in the report, so it
  prints without a dark block.
