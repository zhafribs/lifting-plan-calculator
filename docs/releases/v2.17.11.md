# Lifting Plan Calculator 2.17.11

**Released 21 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The Outrigger's soil / rock description list now opens like every other picker
in the app. No calculation changed.

## Fixed

- **The soil / rock description list matches every other dropdown.** It was the
  one control still opening the platform's own list, which renders as a large
  box under XWayland and did not look like the rest of the app. It now uses the
  same drawn list, keyboard control and highlight as the ground category, pad
  shape and every other picker.

## Notes

- No arithmetic, verdict or limit changed.
- The Windows installer still carries the WebView2 bootstrapper.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime; the installer
  carries its bootstrapper.
- Updating from 2.17.10 keeps every setting.
