# Lifting Plan Calculator 2.16.13

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The Add buttons now belong to the palette, and explicit Light/Dark themes carry
the palette accent in their surfaces. The lift maths, report and PDF are
unchanged.

## Changed

- **Add buttons follow the palette.** They were a fixed green that did not
  belong to the desktop accent. They now use the accent-tinted fill and border
  with the normal text colour, so they match a lavender, brown or blue desktop.
  Status and capacity bands keep their semantic green, amber and red.
- **Explicit Light and Dark surfaces are visibly tinted.** The previous tint was
  so faint that a light theme read as flat white and a dark one as flat black.
  The app's own surface ladder now carries the wallpaper accent more clearly:
  a brown accent gives cream/light brown and dark brown, a lavender accent gives
  the matching light and dark lavender. `Match the desktop` still copies the
  desktop's exact palette, so the shell keeps matching terminals and GTK apps.

## Notes

- This is a styling change only. No data, plan or chart format changes, so there
  is nothing to migrate.
- The printed report is still on white paper and is unaffected.
- On a desktop that publishes no wallpaper palette, an explicit Light/Dark uses
  the neutral palette; only the accent-driven controls change.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.
