# Lifting Plan Calculator 2.16.8

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Follows the wallpaper the way the rest of the desktop does, and fixes the
section title that ended up alone at the foot of a page.

## Fixed

- **The app now paints with the desktop's own palette.** On a Noctalia desktop,
  the colours live in the generated GTK stylesheet — the same `accent_color`,
  `window_bg_color`, `window_fg_color` and `headerbar_bg_color` the terminals and
  the file manager use. The app read only the terminal's 16 colours and picked
  the most vivid one, which on a pink wallpaper was a yellow. It now reads the
  GTK roles first and uses the desktop's background, surface and text directly;
  the wall of panels, rail and inputs is the same warmth as everything else.

- **Wallpaper changes arrive on their own.** Besides the refresh on focus, the
  palette is re-read every 20 seconds while the window is in front — no restart,
  no alt-tab.

- **"Lift Input Parameters" no longer sits alone at the bottom of a page.** The
  keep-with-next rule only covered `section-card`, but that section and others
  are built in an `input-card`. The rule is now on every report heading and the
  block it introduces, both sides. Measured on the same layout: same page count,
  and the title moves to the page with its table.

## Notes

- If the desktop publishes no palette, the app keeps its own neutral pair; the
  hue-tinted fallback is still there for pywal and wallust.
- Nothing changed in the calculation, the load chart reader or the printed
  diagram.
