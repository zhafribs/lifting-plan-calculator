# Lifting Plan Calculator 2.17.7

**Released 21 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The Overall Weight lines are rebuilt as a ledger, every result list in the app
now uses the same figure scale, and the printed outrigger section loses a
sentence it already said in a row. No calculation changed.

## Changed

- **Load and tackle lines are ledger rows.** A line leads with its name and its
  result — description on the left, subtotal on the right, on one edge down the
  card — and carries the working underneath: measured-by, quantity, and the
  measurement. Rows are separated by hairlines rather than nested cards.
- **The measurement boxes fit their figures.** One box for fixed weight; two
  side by side for per-metre and per-volume, sized to `00.0` for metres and
  `0000.0` for the per-unit figures, so they stay compact at every width.
- **The description looks typeable**, and the add row is a dashed accent row
  instead of a filled bar.
- **Every result list uses the same scale.** Values are 600 weight with a small
  muted unit on the crane, sling, outrigger, tandem and summary cards, so the
  overall weight remains the single coloured hero figure.
- **The outrigger report no longer repeats the stiffener rule.** The section
  already has a `Stiffeners` row; the prose note that duplicated it is gone.

## Fixed

- **A two-box measurement never stacks.** When the working line is too narrow,
  the pair moves to a line of its own and stays side by side.
- **Summary values no longer run into their labels** at narrow widths.

## Notes

- No calculation, report content beyond the removed duplicate note, or PDF
  layout change.
- The Windows installer still carries the WebView2 bootstrapper.
