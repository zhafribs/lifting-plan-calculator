# Lifting Plan Calculator 2.15.1

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Two visual defects in the Windows Fluent shell are fixed. The lift maths and the
report are unchanged.

## Fixed

- **A dropdown now looks like a dropdown.** The Windows stylesheet reset the
  select's chevron and its right padding when it restyled fields, so every
  `<select>` looked exactly like a text input. The chevron is back, with the
  same Fluent treatment as the rest of the field.
- **The Qty field no longer overlaps the Measured-by select.** In the narrow
  two-line load row — a small window with the rail expanded — the Qty column
  could shrink below the field's 62 px width, so the field spilled under the
  select. The Qty column now keeps its width and the select takes the remaining
  space.

## Not changed

- The calculation engine, the load-chart reader, the working-range diagram, the
  printable report and the PDF output.
- Linux and macOS appearance.

## Notes

- This is a stylesheet-only patch. No data, plan or chart format changes, so
  there is nothing to migrate.
- `cargo run -- --platform-preview=windows` remains the Linux layout preview;
  Mica needs a Windows 11 build.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.
