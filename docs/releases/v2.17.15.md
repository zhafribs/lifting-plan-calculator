# Lifting Plan Calculator 2.17.15

**Released 23 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Geometry workings now pair by what they actually print, so the angle and
vertical height sit together instead of each taking a row. No calculation
changed.

## Changed

- **Geometry blocks pair by printed width.** The fit check counts the glyphs a
  formula prints, not its LaTeX markup. A two-line working that fits a
  half-column now shares a row.
- **The bridle first step stays alone.** Centroid Radius is calculated before
  the rest, so it keeps the full row; the sling angle and vertical height then
  sit side by side.
- **Less paper.** The fixture report drops from nine pages to eight at 100%
  scale.

## Notes

- No arithmetic, verdict or limit changed.
- The Windows installer still carries the WebView2 bootstrapper.
