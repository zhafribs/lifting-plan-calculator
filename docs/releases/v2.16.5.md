# Lifting Plan Calculator 2.16.5

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Two small things that make the app easier to live with: the appearance moved to
its own Settings page, and an Arch update no longer dead-ends when the desktop
has no polkit.

## Added

- **Settings, above About.** The colour scheme — Match the desktop, Light or
  Dark — lives there now, with a line saying where the accent came from (the
  desktop palette, the desktop accent, or the app's own blue). About keeps the
  update path and the credits.

- **The Arch update tells you what it is missing.** The in-app install runs
  through `pkexec`, which needs polkit and a polkit authentication agent. When
  one is absent, About now names it and gives the exact command:
  - no `pkexec` at all → `sudo pacman -S --needed polkit`
  - no authentication agent (common on a bare Hyprland session) →
    `sudo pacman -S --needed hyprpolkitagent` and
    `systemctl --user enable --now hyprpolkitagent`; other desktops get
    `polkit-gnome` instead.

  Each command has a copy button, and the button can be pressed again straight
  afterwards.

- **The manual update is always offered.** Next to any of the above, About shows
  `sudo pacman -U '<file>'` for the release file it already downloaded and
  verified, so the button is never the only way.

## Notes

- A password prompt you cancel installs nothing and suggests nothing — no
  packages appear without your word.
- Nothing changed in the calculation, the report or the printed diagram.
