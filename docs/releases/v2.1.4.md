# Lifting Plan Calculator 2.1.4

**Released 9 October 2026** · Linux (AppImage)

One consistent layout on every tab. The calculations are unchanged.

## Changed

- **One consistent layout on every tab.** All wide windows now use the same
  60/40 two-column split (Overall Weight, Crane, Graph, Uniform Load, Nonuniform
  Load, Tandem and Summary), and every tab's content fills the same width
  instead of each tab shrinking to fit its own content. On the Summary tab the
  split is mirrored (40/60) so the report preview gets the wider column. Stacked
  (narrow) windows are unchanged.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch. There is no Windows build
  before 2.2.0.
