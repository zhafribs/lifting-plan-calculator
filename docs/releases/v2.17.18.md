# Lifting Plan Calculator 2.17.18

**Released 26 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

A small accessibility and diagnostic pass: toasts now carry a live-region role,
Save as HTML has its own icon, a failed screen is named in the log, and the
release signer's lockfile is audited. No arithmetic or report content changed.

## Changed

- **Toasts announce themselves.** Success and information use `role="status"`;
  failures use `role="alert"`, so assistive tech can announce the result. Save
  as HTML now has its own code icon instead of sharing the PDF file icon.
- **Diagnostics name a failed screen.** A screen factory that throws is logged
  as `screen <key> failed` before the error reaches the global handler.
- **The unused Inter italic asset is gone.** Nothing loaded it; the remaining
  variable face is unchanged.

## Security

- **The signer lockfile is audited in CI.** `tools/sign-manifest/Cargo.lock`
  now goes through the same `cargo audit --deny warnings` gate as the app
  lockfile.

## Notes

- No arithmetic, verdict, limit, report content, footer or PDF layout changed.
- The printed report and its PDF are unchanged.
- `role="status"` announcements depend on the assistive technology; the markup
  is now present, but no screen-reader run was possible here.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
