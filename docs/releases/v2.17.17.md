# Lifting Plan Calculator 2.17.17

**Released 26 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The Summary export card now has one clear primary action, and the shell lost a
little decoration. The report, arithmetic and PDF content are unchanged.

## Changed

- **One primary export.** Save as PDF is the primary action; Print is secondary;
  Save as HTML and Open in browser sit together as tertiary actions. The PDF
  stays the stamped A4 deliverable.
- **Open in browser always opens the current plan.** It builds the current
  export first and reuses the saved file only when it is byte-identical, so a
  plan edited after saving can no longer open from the older file. After an edit
  it can ask for a filename.
- **Copy corrected.** The false "Use in report" note is gone; the margins
  sentence now says they are the values in the preview bar, and the print
  guidance covers both the saved HTML and Print.
- **Quieter surfaces.** The active-nav and card-head gradients are removed, and
  toasts use a 1px status border in the readable status colour instead of a 3px
  side tab.

## Notes

- No arithmetic, verdict, limit, report content, footer or PDF layout changed.
- The printed report remains A4 with the margins set in the preview bar and the
  footer on every page.
- The status borders clear the non-text contrast floor in light and dark on both
  Linux and Windows.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.
