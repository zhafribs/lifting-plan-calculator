# Lifting Plan Calculator 2.2.0

**Released 9 October 2026** · Linux (AppImage) · Windows 10/11 (x64)

The first release with a Windows build, and the first whose AppImage can update
by fetching only what changed.

## Highlights

- **Windows installers.** Windows 10/11 is now supported. Each release carries a
  WiX `.msi` and an NSIS `-setup.exe` built from the same Rust/Tauri source on
  GitHub's Windows runners. The saved-report button uses the platform's own
  opener (`start` on Windows, `xdg-open` on Linux).

- **AppImage delta updates.** A `.AppImage.zsync` sidecar now ships with every
  AppImage, so `appimageupdatetool` fetches only the changed blocks when
  updating to a newer version instead of the whole file.

## Changed

- **Standardised release asset names.** Linux is
  `Lifting-Plan-Calculator-<version>-linux-x86_64.AppImage` (plus `.zsync`);
  Windows is `Lifting-Plan-Calculator-<version>-windows-x86_64.msi` (plus
  `-setup.exe`). Assets from earlier releases keep their old names — this only
  affects new downloads.

## Compatibility and upgrade notes

- Updating from an earlier AppImage: download this release's file once by hand.
  The `.zsync` sidecar only helps from this version onward.
- **Linux.** glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- **Windows.** Windows 10/11 x64 with the WebView2 runtime.
