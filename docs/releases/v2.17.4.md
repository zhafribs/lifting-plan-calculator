# Lifting Plan Calculator 2.17.4

**Released 20 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The per-metre and per-volume load line is laid out in the order it is read, and
the Linux rail still collapses from the header button.

## Fixed

- **The load line reads "Weight by Metre", then "kg/m", then the quantity and
  "m".** 2.17.3 put the "Measured by" dropdown on its own full-width line with
  both value boxes beneath it. The dropdown is now beside the first value box,
  and the quantity sits beside the second:
  - per metre: `Weight by Metre` + `kg/m`, then `Qty` + `m`;
  - per volume: `Weight by Volume` + `m3`, then `Qty` + `kg/m3`.
  The subtotal closes the row. A fixed-weight line keeps its one-box layout.

## Notes

- No calculation, report content or PDF layout changed.
- This replaces the row arrangement in 2.17.3, which is left as published.
- The rail toggle added in 2.17.3 is unchanged.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime; the installer
  carries its bootstrapper.
- Updating from 2.17.3 keeps every setting.
