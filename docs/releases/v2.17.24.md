# Lifting Plan Calculator 2.17.24

**Released 28 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Plans can now be saved to a file you choose and opened again. No plan is
kept between launches unless you save one. No arithmetic, verdict or report
content changed.

## Added

- **Save and open a plan.** The Summary screen writes the plan to a JSON file and
  opens it again: every input, the section switches, page breaks, sign-off lines,
  footer, margins, diagram scale, the diagram's drawing state and the issue
  date. Results are recomputed when it opens: with the same app version it
  prints the same figures, and the file records the inputs and the issue date.
- **The file is checked before use.** A file with a wrong format or version, a
  missing top-level field, a number out of range or an unknown option is refused
  with a message, and the open plan is left untouched. Missing inner values fall
  back to the form's own defaults.

## Notes

- No arithmetic, verdict, limit or report content changed.
- The printed diagram is redrawn from the saved drawing state, sweep labels included.
- The workbook's table view is not saved. The chart points, the boom and radius
  lists and the chart label are, so the capacity check and the report are
  complete; re-import the workbook to see the full sheet again.
- A saved plan keeps its issue date; a new plan gets today's.
- The privacy promise changes in one sentence: no plan is stored between launches
  unless you save one. The update check only reads; the startup log
  (automatic) and the appearance file (when you change the theme) are the only
  other writes.
- The plan file is version 1. A file from a future version is refused by name
  rather than half-read.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
