# Lifting Plan Calculator 2.9.2

**Released 16 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

A pipeline-only release. The application is unchanged from 2.9.1; this build
exists so the release log is clean of the two warnings 2.9.1 still carried.

## Fixed

- **The release PDF check no longer logs a dbind warning.** Its GTK print now
  runs with `NO_AT_BRIDGE=1`: there is no accessibility bus in the headless
  session, and asking for one only wrote a warning.

- **Publishing no longer logs a Node deprecation.** The build artifacts are
  downloaded with `gh run download` instead of a Node action that still calls
  `new Buffer()`. The draft-then-publish behaviour is unchanged.

## Notes

- No calculation, chart reading, report layout, PDF output or page-margin
  behaviour changed. If you already run 2.9.1 there is nothing to upgrade for.
- The dependency audit gate from 2.9.1 is unchanged: zero vulnerabilities, and
  the two advisories this project cannot act on are recorded in
  `.cargo/audit.toml`.
