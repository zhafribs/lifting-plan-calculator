# Lifting Plan Calculator 2.2.1

**Released 10 October 2026** · Linux (AppImage) · Windows 10/11 (x64)

A single fix on top of 2.2.0. The calculations are unchanged.

## Fixed

- **No more "ResizeObserver loop completed with undelivered notifications."
  banner on the Graph tab.** The working-range diagram resized its canvas bitmap
  inside the ResizeObserver delivery cycle, which WebKitGTK reports as an error.
  The redraw is now deferred to the next animation frame, and the global error
  handler treats that specific recoverable message as the warning it is: logged,
  never shown as a startup-error banner.

## Compatibility and upgrade notes

- **Linux.** glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- **Windows.** Windows 10/11 x64 with WebView2.
