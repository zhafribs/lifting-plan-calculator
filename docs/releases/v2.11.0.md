# Lifting Plan Calculator 2.11.0

**Released 16 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

Hardening from the security audit: an update must be newer than the build you
have, and nothing in the app can be pointed at a file you did not choose.

## Security

- **Downgrades are refused.** The release tag is read from the installer's own
  URL and compared with the running version, so replaying an older, correctly
  signed release is rejected instead of installed.

- **Release URLs are parsed.** Scheme, host and repository path are checked
  properly, so a URL that merely begins with the release prefix no longer counts.

- **The installer name must be a file name.** A name that resolves outside the
  update folder (`..\..\Startup\x-setup.exe`) is refused rather than written.

- **A workbook can only be read from the picker's path.** *Load chart* hands the
  app one path; importing anything else is refused, and the permission is spent
  once. The `--chart=` launch hook still works because it registers its path the
  same way.

- **The report save dialog cannot be pre-targeted.** It is filled with a bare
  file name and the report is written with an `.html` extension.

- **The checksum manifest is verified against the build.** Each build job records
  its artifacts' SHA-256 where they are produced; the publish job refuses a file
  that does not match before signing and publishing. `SHA256SUMS.txt` is now a
  comparison, not a restatement of whatever the artifact store handed over.

## Notes

- No calculation, report or PDF behaviour changed.
- The 2.10.0 signing key and `SHA256SUMS.txt.sig` are unchanged; this release is
  signed with the same key.
- Windows installers still carry no Authenticode certificate; applying to a free
  open-source signing service is the remaining step for the "Unknown publisher"
  warning, and nothing in the app depends on it.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- No plan is stored between launches, so there is nothing to migrate.
- Windows needs the WebView2 runtime, as before.
