# Lifting Plan Calculator 2.16.6

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

A tidy-up of where things live: the update controls now sit with the appearance
in Settings, and About is what it says it is.

## Changed

- **Updates moved to Settings**, in a card under Appearance. It is the same
  behaviour as 2.16.5 — check, Download & update for the AppImage, Download &
  install for the Windows installer and the Arch package, the polkit help, and
  the always-available manual `sudo pacman -U` command — in one place.

- **The launch reminder is a reminder.** It still says a newer release exists and
  links to its notes, but its action is now Show updates, which opens Settings.
  The installer buttons it used to duplicate are gone, so there is one set of
  update paths to keep correct.

- **About** keeps the hero, what the app does, the developer and the credits.

## Notes

- Nothing changed in the calculation, the report, the printed diagram or the
  appearance itself.
