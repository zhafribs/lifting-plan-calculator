# Lifting Plan Calculator 2.17.23

**Released 27 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Repeated failures are counted instead of stacking, two notices are both written
to the live region, a stuck preview recovers, and more controls carry a name for
assistive tech. No arithmetic or report content changed.

## Changed

- **Repeated failures are counted, not stacked.** A message that repeats on the
  same notice shows a count (×2) instead of adding another and pushing out one
  you have not seen.
- **Two notices in one moment are both written.** Each message goes to the live
  region in turn instead of only the last, so assistive tech can announce both.
- **A stuck page render recovers.** The preview gives up after 15 seconds,
  says so, and returns to the Live preview.
- **More controls are named.** The zoom buttons, the load and tackle remove
  buttons, the working-range chart and the page view read as themselves rather
  than as a glyph or an unnamed region.

## Notes

- No arithmetic, verdict, limit or report content changed.
- The PDF text layer still drops a few punctuation glyphs in diagram labels; the
  printed page is correct. The full-face experiment in `docs/roadmap.md`
  confirms the document engine, not the embedded subset, is the cause.
- A real screen-reader pass is still owed; the code audit and its five-step
  checklist are in `docs/accessibility.md`.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
