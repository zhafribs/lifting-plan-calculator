# Lifting Plan Calculator 2.13.0

**Released 17 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

A new Outrigger Pad Size tab, and the Linux AppImage can now update itself.

## Highlights

- **Outrigger Pad Size.** The new tab sizes the bearing area under one
  outrigger from the BS 8004 Table 1 presumed allowable bearing values adapted
  for Malaysian practice. It carries the ground category, description, bearing
  value, crane mass, lift load, square or rectangular pad, use check and a
  printable report section.
- **The AppImage updates in place.** On Linux the update reminder now downloads
  the new AppImage, verifies its signed checksum, replaces the running file and
  restarts the app. The old AppImage is removed after the new one starts.

## Added

- **Outrigger Pad Size tab.** The calculation is
  `A = 0.65 x (CM + L) / V`, where `CM` is the crane mass in kN, `L` is the
  lift load in kN and `V` is the maximum permissible bearing value in kPa. The
  result shows the required area, the minimum square pad rounded up to 50 mm,
  the selected pad's applied pressure and utilisation, and a plan-view sketch.
- **BS 8004 Table 1 ground picker.** The ground category, soil or rock
  description, published value and field note are selected in the tab. The same
  table ships as
  `docs/examples/Presumed Allowable Bearing Values (BS 8004 Table 1).xlsx`.
- **Outrigger report section.** Summary can include the new pad calculation as
  its own section, with the ground row, formula, required area and selected-pad
  check.

## Changed

- The Excel workbook table starts collapsed after an import, so the boom and
  radius controls stay in view. Click the table toggle to read the rows.

## Fixed

- **The Linux AppImage update button works.** It downloads the new AppImage,
  proves the release's signed `SHA256SUMS.txt` and the AppImage digest, replaces
  the running file and restarts the app. The old file is removed after the new
  one starts and restored if the new one does not.

## Notes

- The outrigger calculation sizes the bearing **area** only. Pad thickness,
  steel plate design, timber grade and the crane manufacturer's outrigger
  reaction are separate checks.
- Ground rows marked **Not applicable**, including peat, organic soils and
  uncontrolled fill, are refused for shallow pads.
- Windows and the report output are unchanged.

## Compatibility and upgrade notes

- **Updating from an older AppImage:** install 2.13.0 manually from this release
  page once. The older AppImages do not carry the in-app update button. From
  2.13.0 onward the button can replace the AppImage itself.
- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows needs the WebView2 runtime, as before; the installers remain unsigned,
  so SmartScreen shows "Unknown publisher".
- No plan is stored between launches, so there is nothing to migrate.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
