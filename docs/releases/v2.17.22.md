# Lifting Plan Calculator 2.17.22

**Released 26 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The working-range diagram now matches the light scheme instead of sitting dark
on a light window. No figures, verdicts or printed output changed.

## Fixed

- **The working-range diagram follows the colour scheme.** On a light scheme the
  chart is drawn in the colours the report prints — pale grid, dark labels, the
  same amber and blue. The below-ground warning red is darkened on screen so it
  stays readable. A dark scheme keeps the dark chart it always had. A theme
  change repaints an open chart instead of leaving the old palette.

## Notes

- No arithmetic, verdict, limit or report content changed.
- The printed report is unchanged: the print path always starts from the dark
  palette, so the page prints exactly as before.
- The light chart is the printed chart's palette, with one exception: the
  below-ground warning red is darkened for the screen, because the printed red
  is too faint to read there.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
