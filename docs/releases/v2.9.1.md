# Lifting Plan Calculator 2.9.1

**Released 16 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

A maintenance release: the dependency tree is audited and gated, and the build
logs are clean on every platform. The app behaves as 2.9.0 did.

## Highlights

- **No known vulnerabilities.** The lockfile was refreshed (rustls 0.23.46,
  rustls-webpki 0.103.17, webpki-roots 1.0.12, ctutils 0.4.8, rustix 1.1.6,
  tokio 1.54.1 and the rest), and `cargo audit` now reports zero
  vulnerabilities with no warnings. The audit gates the build: a new advisory
  fails CI instead of being printed and ignored.

- **The two advisories this project cannot act on are recorded, not hidden.**
  `.cargo/audit.toml` lists `proc-macro-error` (unmaintained build-time macro,
  no fixed upgrade, never in the shipped binary) and `glib 0.18` (an unsound
  iterator the app never uses, pinned by Tauri's GTK binding), each with its
  reason.

- **Clean CI logs.** The Windows compiler no longer warns about an unused `mut`
  in the PDF workspace, the release notes are published with `gh` rather than a
  Node action, and the accessibility-bus and git default-branch messages are
  gone from the logs.

## Notes

- No calculation, chart reading, report layout or PDF output changed.
- The printed page keeps one-inch margins by default, with the **Margins**
  control beside *Refresh* as before.
