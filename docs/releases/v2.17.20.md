# Lifting Plan Calculator 2.17.20

**Released 26 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The printed diagram keeps the app's typeface, the PDF is smaller, and a failed
action stays on screen until you dismiss it. No arithmetic or report content
changed.

## Changed

- **The printed diagram keeps Inter.** A 71 KB subset of the bundled face is
  embedded in the SVG, so the PDF labels no longer fall back to the system sans;
  the labels are measured with the document Inter, whose metrics the subset
  matches. The same plan exports about 23% smaller than with the raster diagram
  (689,927 B against 895,745 B for one measured plan).
- **Error messages stay until dismissed.** Every notice carries a close button.
  A failure no longer disappears after six seconds; at most four notices are
  kept, and a transient notice gives way before a failure does.
- **Success messages are announced politely.** Information and success notices
  go through a polite live region, so assistive tech can announce them without
  an assertive interruption.

## Notes

- No arithmetic, verdict, limit, report content, footer or page margin changed.
- The diagram's embedded subset covers Basic Latin and the degree sign, which is
  everything the diagram prints.
- The 23% figure is one measured plan, not a promise for every plan.
- Semi-transparent shapes that overlap one another are an approximation against
  the old flattened pixel; opaque and high-alpha colours match.
- In the PDF text layer, a few punctuation glyphs inside diagram labels (such as
  `=`) may not extract; the printed page is unaffected.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
