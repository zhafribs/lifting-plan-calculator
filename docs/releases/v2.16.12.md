# Lifting Plan Calculator 2.16.12

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Light and Dark now fully override the desktop palette, and the Windows title bar
follows the same choice. The lift maths, report and PDF are unchanged.

## Fixed

- **An explicit Light or Dark choice changes the whole shell.** When the desktop
  published a palette for the other scheme — a dark Noctalia palette while
  choosing Light — those tinted surfaces were applied anyway. The scheme switch
  repainted the tokens outside that palette, but the backgrounds, text and
  borders stayed on the desktop's colours, so the result looked partially
  applied. The desktop palette is now used only when its scheme matches the
  resolved scheme; an override uses the app's own light or dark palette, tinted
  from the wallpaper accent when there is one.

  This is why the setting could look correct on one machine and wrong on
  another: the bug needed a published desktop palette whose scheme was the
  opposite of the chosen one.

- **The Windows title bar follows the in-app scheme.** The page could switch to
  Light while the native title bar and Mica stayed on the Windows theme. The
  window theme is now set alongside the page: `system` follows Windows, and an
  explicit Light or Dark applies to both.

## Notes

- This is a styling and window-chrome change. No data, plan or chart format
  changes, so there is nothing to migrate.
- On Linux, the window theme remains app-wide and follows the desktop; the fix
  is in the page palette.
- `Match the desktop` still uses the desktop's exact palette, so the app keeps
  matching the rest of the system.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.
