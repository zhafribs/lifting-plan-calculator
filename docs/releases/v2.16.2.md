# Lifting Plan Calculator 2.16.2

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

A structure release: the same app, arranged so the next person can find their way
around it.

## Changed

- **[`docs/architecture.md`](https://github.com/zhafribs/lifting-plan-calculator/blob/main/docs/architecture.md)**
  is the map: what each Rust module, frontend module and stylesheet is
  responsible for, where to add a screen, a report section, a command or an
  update path, and where the tests live.

- The report's stylesheet moved from `report.rs` to `report_style.rs`; it is one
  string on purpose, because the page view, the PDF export and the browser
  fallback all print from it.

- The palettes and measurements moved from `app.css` to `tokens.css`. `app.css`
  now holds layout and components only and reads token names — so a new palette
  is a block in one small file, not a second copy of the screens.

## Notes

- No behaviour changed: the same 253 Rust tests and 25 frontend tests pass, and
  the palettes render as they did in 2.16.0.
- The seams that remain (the diagram screen, the export probe) are listed at the
  end of the architecture note with the order they should be taken in.

## Compatibility and upgrade notes

- From 2.16.1 on, an Arch install updates itself from About. Older installs
  update once with `sudo pacman -U ./Lifting-Plan-Calculator-2.16.2-linux-x86_64.pkg.tar.zst`.
- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
