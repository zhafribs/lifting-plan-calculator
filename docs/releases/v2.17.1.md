# Lifting Plan Calculator 2.17.1

**Released 20 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Repository guidance for coding agents, and the version bookkeeping that goes
with it. **No application change** — the calculator, the report and the PDF are
the same as 2.17.0.

## Added

- **`AGENTS.md`** at the repository root: the commands that build, test and lint
  the project, the layout of the Rust engine and the `ui/` modules, and the rules
  the build enforces — the ported test literals, the release notes and council
  record a tag needs, and the hash-pinned vendored files.
- The file also records the domain rules an agent must not break: the chart is
  the only capacity check, the 75% / 100% bands, every report figure shown as
  its formula, and the app's privacy contract (no stored plan, one update check,
  one log file).

## Changed

- **The version now lives in three places, and `AGENTS.md` says so.**
  `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json` and `Cargo.lock` must be
  bumped together; the release gate reads `tauri.conf.json`.

## Notes

- This is a documentation-only patch. The installed binaries differ from 2.17.0
  only in their version string, so there is no reason to update for behaviour.
- No calculation, report, layout or settings change.
- If you build from source, nothing in the build changed either.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
