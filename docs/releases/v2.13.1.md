# Lifting Plan Calculator 2.13.1

**Released 17 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

The Outrigger Pad Size form is easier to use and reuses the rest of the sheet.

## Fixed

- **Ctrl+3 opens Outrigger Pad Size.** The left pane now shows the shortcut on
  the tab, and Graph, Uniform Load, Nonuniform Load, Tandem and Summary move to
  **Ctrl+4** through **Ctrl+8**.
- **The bearing-value row has room.** `Max permissible SBC (V)` sits below the
  ground selectors with its own spacing, the value field is narrower, and the
  `kPa` unit is smaller.
- **The load fields are named clearly.** `Crane mass (CM)` and `Lift load (L)`
  replace the old labels.
- **The loads follow the sheet by default.** `CM` defaults to the Crane tab's
  rated capacity, converted from tonnes to kN. `L` defaults to the Overall
  Weight gross load. Editing either field breaks the link; **Use crane tab** and
  **Use overall weight** reconnect it.

## Notes

- The outrigger formula, ground table, pad check and report section are
  unchanged from 2.13.0.
- The Linux AppImage self-update added in 2.13.0 is unchanged. A 2.13.0 AppImage
  can use the update button; older AppImages still need the one-time manual
  install.
- Windows and the report output are unchanged.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows needs the WebView2 runtime, as before; the installers remain unsigned,
  so SmartScreen shows "Unknown publisher".
- No plan is stored between launches, so there is nothing to migrate.
