# Lifting Plan Calculator 2.16.10

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Numbering that follows the plan, one sling arrangement at a time, and the
Windows installer error fixed.

## Fixed

- **Section numbers match the printed plan.** The builders wrote their own
  numbers, so adding the outrigger pad gave two "2." headings and pushed the
  rest out of step. The report is now renumbered in the order its cards appear:
  with crane, working-range diagram, outrigger pad and uniform load ticked, the
  cards are 1 to 6, ending on FINAL CAPACITY & EQUIPMENT SELECTION.

- **`3. LIFT INPUT PARAMETERS - UNIFORM LOAD`.** The uniform load inputs say
  which arrangement they describe.

- **Uniform, Nonuniform and Tandem replace one another.** They are three
  descriptions of the same lift, so ticking one clears the other two — including
  their New page ticks.

- **Windows: updating no longer stops at "requires elevation" (os error 740).**
  The per-machine setup cannot be launched directly from an app that is not
  elevated; the app now asks Windows to run it with the administrator prompt the
  installer expects. The old message also told you nothing; if it ever fails
  again, it names the saved installer so it can be run by hand.

## Notes

- Nothing changed in the calculation, the load chart reader or the printed
  diagram.
