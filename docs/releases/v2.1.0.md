# Lifting Plan Calculator 2.1.0

**Released 9 October 2026** · Linux (AppImage)

A usability release that keeps the important things in view at any window size,
with no change to the calculations.

## Highlights

- **Independent scroll panes on wide windows.** Uniform Load, Nonuniform Load and
  Tandem each split into a form column and a results column that scroll on their
  own, so one side keeps its place while the other moves. Stacked (narrow)
  windows keep the single scroll they had before.

- **Always-visible working range diagram.** On the Graph tab the diagram fills
  its column and rescales, so it stays in view while the boom configuration,
  boom angle and envelope, and readout scroll beside it.

## Fixed

- **Rail footer.** The app name, version and contact are no longer hidden when
  the window is at its smallest size. The footer stays pinned beneath the icon
  rail and the navigation list scrolls on its own, so the product identity is
  visible at every window size.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch. There is no Windows build
  before 2.2.0.
