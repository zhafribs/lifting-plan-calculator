# Lifting Plan Calculator 2.17.0

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Settings now offers three fixed palettes beside the desktop's own colour. The
set is intentionally small, and every accent is contrast-checked.

## Added

- **Clay, Lavender and Pine in Settings.** Each palette has a light and a dark
  accent, and the shell's surfaces are tinted to match. Clay is a warm brown,
  Lavender a cool violet, Pine a muted green. The scheme still decides light or
  dark; the palette decides the colour family.
- **`Match the desktop` stays the default.** It keeps following the system's
  light/dark choice, its accent and, where the desktop publishes one, its exact
  palette.
- The choice is remembered beside the scheme in
  `~/.config/lifting-plan-calculator/appearance.json`. An existing file without
  the new key reads as `Match the desktop`.

There is deliberately **no free colour picker and no larger palette grid**: a
fixed set keeps button, focus and status contrast predictable and stops the
shell turning into a theme shop. Status and capacity bands keep their semantic
green, amber and red in every palette.

## Fixed

- **Filled accent buttons choose the readable text colour.** The old rule used a
  luminance threshold, which gave mid-tone accents like Clay white text at about
  2.9:1. The app now compares black and white directly; Clay gets black at about
  7:1, while dark blue and deep green keep white.

## Notes

- Styling only: the calculation engine, load-chart reader, report and PDF are
  unchanged.
- The printed report is still on white paper.
- A desktop that publishes no wallpaper palette still gets a neutral surface
  ladder; the chosen curated palette supplies its own accent and tint.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).
- The Windows installers are per-machine, so an existing per-user install is
  replaced by the per-machine one.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
