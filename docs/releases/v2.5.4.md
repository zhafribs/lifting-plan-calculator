# Lifting Plan Calculator 2.5.4

**Released 14 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

*Save as PDF* now works on a machine with no browser installed: the AppImage
carries its own pinned headless Chromium. The same change fixes the reason the
previous AppImage reported "no PDF renderer was found" even where Chromium was
installed.

## Highlights

- **The PDF export is self-contained.** The AppImage bundles Chrome for
  Testing's headless shell (157.0.8103.78, pinned and checksum-verified at build
  time), so the export needs nothing from the target machine. It is preferred
  over a system browser; a system Chromium remains the fallback, and Windows
  keeps using Edge.

- **A browser already installed is now found.** Inside the AppImage, external
  programs were started with the AppImage's own library path, so a system
  Chromium died on `undefined symbol: BrotliDecoderAttachDictionary` and looked
  absent. The renderer and the desktop opener now run with that environment
  stripped, and the search also covers `/usr/bin`, `/usr/local/bin` and
  `/snap/bin`.

## Notes

- **The download is larger.** Bundling the renderer adds about 100 MB: the
  AppImage is roughly 180 MB instead of 82 MB. That is the cost of the feature
  working with nothing installed; the build fetches the renderer once and CI
  caches it under the pinned version.
- The renderer's license text ships inside the payload
  (`LICENSE.headless_shell`), and `THIRD_PARTY_NOTICES.md` names the component.
- No calculation, chart or report layout changed in this release.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- No plan is stored between launches, so there is nothing to migrate. The PDF
  export now needs no browser on Linux; Windows uses the Edge that ships with
  the system.
