# Lifting Plan Calculator 2.8.1

**Released 14 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

A patch for saving on Windows, and for the dependency update that broke the
Windows build.

## Fixes

- **A failed save leaves the plan you already had.** The export used to delete
  whatever was at the chosen name before moving the new PDF in. Windows replaces
  on rename anyway, so that step was unnecessary and destructive: when the save
  then failed, your previous plan was gone and the new one was not there either.
  The move is now a single replacing rename; it is retried only while another
  program is momentarily holding the file, and a refusal now names the file and
  whether it is read-only or in use.

- **The footer is written beside the printed file, not over it.** The PDF engine
  can still hold the file it has just written when it reports that it finished;
  writing the footer into that same file could be refused. The footered pages
  are now produced as a separate file and moved into place, so nothing is written
  over a file another process may still have open.

- **The Windows build can be updated again.** A dependency bot raised
  `windows-core` on its own while the WebView2 bindings still used the previous
  version, which stopped the Windows printer from compiling. Those two packages
  are now excluded from automatic updates, because they have to move together
  with the app framework; the rule is recorded in the code so the next framework
  update moves them deliberately.

## Notes

- **What is tested.** On every change, on Windows through WebView2 and on
  Linux, the export probe saves a new file, replaces that file, writes to a
  folder whose name has spaces and non-ASCII characters, writes into nested
  folders, and then proves two refusals: a PDF held open by another program and
  a folder that cannot be written to. Both refusals must leave the earlier file
  untouched.
- **What is still not exercised.** A network share (UNC or OneDrive-redirected
  Documents), a path near Windows' 260-character limit and a full disk are not
  part of the probe; they fail with a message rather than a crash.
- Linux behaviour is unchanged.
- No calculation, chart or report layout changed in this release.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- No plan is stored between launches, so there is nothing to migrate.
- Windows needs the WebView2 runtime, as before.
