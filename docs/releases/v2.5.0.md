# Lifting Plan Calculator 2.5.0

**Released 13 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

The lift is now checked against the crane the job actually booked, not only
against the point the load chart rates — and a plan carries the details a
checked calculation is expected to carry.

## Highlights

- **The booked crane rating is checked.** The crane's own rating is compared
  with the capacity the lift needs at the 75% rule, and the result governs when
  it fails. A crane too small for the lift can no longer pass because the chart
  reads high. The plan shows both figures, and says *Not checked* when no
  rating has been entered.

- **The plan carries its own details.** The Summary tab has a *Plan details*
  card: plan reference, Prepared by, Checked by and Approved by. They print at
  the top of the plan together with the issue date, blank lines included, so a
  printed copy can be signed.

- **A radius outside the load chart is refused.** The chart lookup used to carry
  the nearest charted capacity in from either end; now a working radius (or a
  jib boom angle) outside the charted range is refused, naming the range the
  chart rates. The plan states the refusal in its crane section instead of
  leaving it out.

## Fixed

- A chart table lists only the radii the selected boom column charts, instead of
  repeating the last charted capacity down every remaining workbook radius.
- A boom switch to a column with no charted capacities no longer publishes the
  previous boom's capacity under the new boom's label.
- A chart imported for a lift no charted radius carries starts at the shortest
  charted radius and reports the overload, instead of leaving the tab blank.
- A workbook that names its own unit ("Unit: ton") is read from that text; the
  magnitude guess is kept only for charts that declare nothing. Small charts
  written in kg were previously read as tonnes, understating usage a thousand
  times.

## Changed

- The Load example charts the radius it reads (8.00 m), so its figures are a
  rated lift rather than a clamped one.

## Added

- Two example load charts ship in `docs/examples/` (35 t TR-350M-1 and 20 t
  TL-200M), each parsed end to end by the test suite.

## Compatibility and upgrade notes

- **A plan that relied on the old clamping will now read differently.** If a
  saved plan was written with a radius past the end of the chart, reloading that
  input now reports a refusal at that radius rather than a carried-in capacity.
  This is deliberate: the carried figure was never a rating the chart published.
- **Linux.** glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- **Windows.** Windows 10/11 x64 with WebView2. Nothing stored between launches,
  so there is nothing to migrate.
