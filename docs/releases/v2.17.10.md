# Lifting Plan Calculator 2.17.10

**Released 21 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The working range diagram starts at half width, so a new plan leaves room for
its details above it. No calculation changed.

## Changed

- **The working range diagram opens at 50%.** The Report sections card starts
  with the diagram ticked and the scale at 50 instead of 100. The field still
  takes 25 to 100, so full width is one edit away.

## Notes

- No arithmetic, verdict or limit changed.
- The Windows installer still carries the WebView2 bootstrapper.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime; the installer
  carries its bootstrapper.
- Updating from 2.17.9 keeps every setting.
