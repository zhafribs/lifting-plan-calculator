# Lifting Plan Calculator 2.16.1

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The Arch package can now update itself from the app, the same way the AppImage
and the Windows installer already could.

## Added

- **Download & install in About.** When the running copy was installed by
  `pacman`, the update check picks the release's `.pkg.tar.zst` and About offers
  to install it. The app downloads the file, verifies it against the release's
  signed `SHA256SUMS.txt`, and hands it to `pkexec pacman -U` — one polkit
  password prompt, then the app closes so you can reopen the new version.

- **A way out when no polkit agent is running.** Minimal desktops, Hyprland
  among them, often have none. The app then changes nothing and shows the exact
  `sudo pacman -U '<file>'` command for the file it already verified, with a
  copy button, so the update is one paste away.

## Notes

- The AppImage and the Windows installer updates are unchanged. A Flatpak copy
  deliberately offers neither: Flatpak updates come from `flatpak update`.
- Deb, rpm and Flatpak copies still update through their package manager; only
  the Arch package installs itself inside the app for now.
- Nothing changed in the calculation engine, the load chart reader, the report
  or the palettes.

## Compatibility and upgrade notes

- Existing Arch installs: update once with
  `sudo pacman -U ./Lifting-Plan-Calculator-2.16.1-linux-x86_64.pkg.tar.zst`;
  from the next release on, About carries the button.
- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime (the installer
  carries its bootstrapper).

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
