# Lifting Plan Calculator 2.16.9

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

You can now decide where a section starts, and the Windows appearance switch
finally does what it says.

## Added

- **New page, per section.** Each row in Report sections has a small **New page**
  tick next to its include tick. Ticked, that section starts on a fresh page —
  in the page view and in the saved PDF. Untick everything and the report lays
  itself out as before, keeping every title with its first block.

## Fixed

- **Windows: Light and Dark work.** The Fluent layer read the operating system's
  colour scheme through a media query, so the Settings switch stored a value that
  nothing used. It now follows the app's own choice; the OS setting is still what
  "Match the desktop" means.

- **Windows: the choice is remembered between launches.** It was saved under
  `$HOME`, which a normal Windows session does not set; it now lives in
  `%APPDATA%\lifting-plan-calculator\appearance.json`.

- **A failed update says where the package is.** If the installer cannot be
  started, the message names the downloaded file, so the update can be finished
  by hand.

## Notes

- Nothing changed in the calculation, the load chart reader or the printed
  diagram.
