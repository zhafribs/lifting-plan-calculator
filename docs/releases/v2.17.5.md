# Lifting Plan Calculator 2.17.5

**Released 20 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

Dropdowns open as a compact list drawn by the app. No calculation changed.

## Fixed

- **The dropdown list is the app's own.** The platform opens a `<select>` as a
  separate window; on some Linux compositors that window is oversized, covers
  the control and makes the selected text look clipped. Every dropdown — the
  load type, the sling arrangement and the rest — now opens a compact list in
  the app's styling, grouped where the options are grouped, and scrolls when
  the list is long.
- The underlying `<select>` still holds the value, focus and keyboard
  behaviour, so the exchange with the engine is unchanged.

## Notes

- No calculation, report content or PDF layout changed.
- Per-metre and per-volume load lines keep the layout from 2.17.4.

## Compatibility and upgrade notes

- AppImage and packages: glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows: Windows 10 or 11, x64, with the WebView2 runtime; the installer
  carries its bootstrapper.
- Updating from 2.17.4 keeps every setting.

**Scope** — a calculation aid for a competent person, not a certified lift plan or an approval. [Scope of use](https://github.com/zhafribs/lifting-plan-calculator#scope-of-use)
