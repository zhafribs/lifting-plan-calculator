# Lifting Plan Calculator 2.6.0

**Released 14 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

The AppImage no longer carries a browser. *Save as PDF* prints the plan with the
web view the app already runs on, so the download is back to roughly its 2.5.3
size while the export keeps working on a machine with nothing installed and
nothing downloaded.

## Highlights

- **One AppImage, about 100 MB smaller.** The bundled headless Chromium is gone:
  the file is about 83 MB instead of 182 MB, and it is still a single download
  with nothing else to pick. The export needs no browser, no network and no
  consent step — it works on an air-gapped machine, and nothing is fetched at
  first use.

- **The footer no longer depends on the Linux renderer.** On Linux the plan
  reference, the credit line and `n / total` are written onto the finished pages
  by the app itself. Chromium builds older than 131 silently drop CSS `@page`
  margin boxes, which used to take the reference and page counter off a printed
  plan; that cannot happen with the footer drawn this way.

- **A failed export no longer leaves a broken plan behind.** The PDF is printed
  and completed beside the file you chose, and the file you chose is only
  replaced once the footer is on every page. Previously a late failure could
  leave a plan without its reference and page numbers at that path. On Windows
  the old file is removed at that last step, when the new one is already
  complete.

- **Same plan, same margins.** A4, one inch on every side, the card layout and
  the typeset equations are unchanged. The export is still one click in Summary
  and still reports the saved path.

## Notes

- **The Linux footer carries names in most scripts.** The typeface is
  embedded in the export — Liberation Serif, the same face the previous Chromium
  build used — so a reference or credit line in Latin with diacritics, Greek,
  Cyrillic or Vietnamese prints as typed. Scripts outside that font (for example
  Chinese or Arabic) still fall back to a placeholder box.
- **The default credit line changed by one character.** Its envelope is now an
  em dash, `Prepared with Lifting Plan Calculator by Zhafri Syazwi — …`, so the
  field in Summary and the printed footer are the same string. Windows prints
  the same new line through Edge; only how the footer is drawn differs.
- **Linux prints with WebKitGTK; Windows still prints with Edge.** Windows 10
  and 11 ship Edge, so it is used there as before, and it keeps drawing the
  footer with its own `@page` margin boxes; Linux draws them onto the PDF. A
  PDF from each platform therefore comes from a different engine and may break
  pages differently, though both print A4 with the same one-inch margin and the
  same footer text.
- No calculation, chart or report layout changed in this release.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- No plan is stored between launches, so there is nothing to migrate. The PDF
  export requires no browser on Linux; Windows uses the Edge that ships with the
  system.
- If you kept the 2.5.4 AppImage for its bundled renderer, it is no longer
  needed: 2.6.0 prints without one.
