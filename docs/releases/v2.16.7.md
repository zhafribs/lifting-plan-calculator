# Lifting Plan Calculator 2.16.7

**Released 19 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The Summary tab's defaults and preview, and a tighter page-break rule for the
printed plan.

## Changed

- **A new plan starts with the crane check alone.** Working-range diagram,
  outrigger pad size, uniform, nonuniform and tandem all start clear; a section
  appears on the plan because it was ticked, not because it was left on.

## Fixed

- **The two preview modes share one frame.** Pages and Live now fill the same
  pane; before, the page list was 40 px shorter and the live frame collapsed to
  its content.

- **The live preview is readable.** It is laid out at the print text width and
  zoomed to fill the pane, so it shows the plan at the same scale as the page
  view instead of at 7 pt in a narrow column.

- **A section title no longer ends a page.** Keep-with-next is stated on both
  sides: the heading may not end a page, and the block it introduces may not
  start one. Measured on a six-section document: same page count as before, no
  orphaned titles. The alternatives that trade paper for certainty were
  measured and rejected — see council decision 0026.

## Notes

- Nothing changed in the calculation, the load chart reader or the accent
  handling.
