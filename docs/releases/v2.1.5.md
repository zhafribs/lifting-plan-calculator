# Lifting Plan Calculator 2.1.5

**Released 9 October 2026** · Linux (AppImage)

A small layout fix on top of 2.1.4. The calculations are unchanged.

## Fixed

- **Double scroll engages the moment a tab can show two columns.** The split cut
  now matches the two-column cut instead of trailing it by 20 pixels. Between
  the two, the Overall Weight, Crane, Graph, Uniform Load, Nonuniform Load,
  Tandem and Summary tabs previously showed their cards side by side with a
  single page scroll — now every wide-enough tab splits into independent scroll
  panes, and below that width everything stacks back into the single scroll.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch. There is no Windows build
  before 2.2.0.
