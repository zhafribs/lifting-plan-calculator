# Lifting Plan Calculator 2.13.2

**Released 18 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

The Outrigger Pad Size tab now reports the minimum pad, and the form is easier
to scan.

## Changed

- **The result is the minimum pad.** The formula already decides the minimum
  bearing area, so the selected-pad applied pressure, utilisation and 90/100%
  bands are removed. A square pad reports the minimum square side. A
  rectangular pad reports the minimum length for the width entered. A larger
  pad is acceptable.
- **The form is reflowed.** The bearing value and the published table value
  share a row, and the crane/lift actions sit on their own line. The `kPa` unit
  and the load buttons no longer crowd the fields.
- The `Ctrl+3` shortcut moved in 2.13.1: Outrigger Pad Size is `Ctrl+3`, and
  Graph, Uniform Load, Nonuniform Load, Tandem and Summary are `Ctrl+4` through
  `Ctrl+8`.

## Notes

- The formula, BS 8004 ground table, crane/lift defaults and report section are
  unchanged. The report now prints the same minimum-pad result as the screen.
- The Linux AppImage self-update added in 2.13.0 is unchanged. A 2.13.0 or newer
  AppImage can use the update button; older AppImages need a one-time manual
  install.
- Windows and the rest of the app are unchanged.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows needs the WebView2 runtime, as before; the installers remain unsigned,
  so SmartScreen shows "Unknown publisher".
- No plan is stored between launches, so there is nothing to migrate.
