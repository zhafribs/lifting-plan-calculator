# Lifting Plan Calculator 2.13.3

**Released 18 November 2026** · Linux (AppImage) · Windows 10/11 (x64)

Outrigger Pad Size now gives thickness guidance, and the printed section is
cleaner.

## Added

- **Pad thickness guidance.** The Outrigger Pad Size tab now chooses steel plate
  or hardwood timber and shows the recommended thickness by crane class:
  - steel plate: 25–32 mm light, 35–50 mm medium, 50–75 mm+ heavy;
  - hardwood timber: 75–100 mm light, 150–200 mm medium, 200–300 mm heavy.
- **45° timber rule.** When the outrigger foot length and width are entered, the
  app raises the timber thickness to roughly the pad overhang when that is
  larger than the class range.
- **Build-up warnings.** Timber pads wider than 1.2 m are flagged for
  cross-layering; steel plates wider than 1.2 m × 1.2 m are flagged for
  40–50 mm plate or welded stiffeners. Plywood, OSB, hollow blocks and
  softwoods are called out as unsuitable.
- The same guidance is structured on the **Thickness** sheet of
  `docs/examples/Presumed Allowable Bearing Values (BS 8004 Table 1).xlsx`.

## Changed

- The outrigger report drops the introductory and closing paragraphs.
- The ground note now comes after the minimum-pad and thickness result.
- The “at 50 mm increments” wording is removed. The minimum-pad sentence keeps
  its normal size.

## Fixed

- **A GitHub API rate limit no longer disables the update check.** The app asks
  the GitHub API first, then falls back to the repository's releases Atom feed
  when the API returns 403. The feed supplies the latest stable tag, and the app
  builds the same release asset names before downloading. The download still
  proves the signed checksum before it is used.

## Notes

- The bearing-area formula, BS 8004 ground table, shortcut and linked loads are
  unchanged from 2.13.2.
- The thickness guidance is preliminary. Pad build-up, steel plate design,
  timber grade and the crane manufacturer's outrigger reaction remain separate
  checks.
- The Linux AppImage self-update still verifies the signed checksum. The update
  check now falls back to the releases Atom feed when the GitHub API is
  rate-limited.
- **A user on 2.13.1 must install 2.13.3 manually once.** The 2.13.1 build does
  not carry the feed fallback, so its update check can still be stopped by the
  GitHub API rate limit. From 2.13.3 the fallback is in place.

## Compatibility and upgrade notes

- glibc 2.35 floor — Ubuntu 22.04+, Fedora 36+, Arch.
- Windows needs the WebView2 runtime, as before; the installers remain unsigned,
  so SmartScreen shows "Unknown publisher".
- No plan is stored between launches, so there is nothing to migrate.
