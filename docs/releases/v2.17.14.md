# Lifting Plan Calculator 2.17.14

**Released 22 November 2026** · Linux (AppImage, deb, rpm, Arch, Flatpak) · Windows 10/11 (x64)

The two capacity workings now sit together, and the lone tension working takes
one line. No calculation changed.

## Changed

- **The capacity workings pair up.** Minimum Required Sling WLL and WLL
  Utilisation sit side by side, each on two lines, for every arrangement.
  Nested lifts pair the first and second sling the same way.
- **The lone tension working takes one line.** It has the full row in Rigging
  Factors & Tension, so it no longer splits in two.
- **The tag-rating verdict stays with its working.** PASS or FAIL prints under
  the utilisation formula; the configured SWL remains below the pair.

## Notes

- No arithmetic, verdict or limit changed.
- The Windows installer still carries the WebView2 bootstrapper.
